# csv_import
conversion de archivos csv a objetos y de objetos  los ingresamos a mysql despues que estan en mysql vamos a consumir los endpoins  por metodos http

### herramientas
-mysql2
-axios
csv-parcer,
-cors,
-path,
-express

### pasos 
**paso 1**
-descargar todas las librerias necesarias 
**paso 2**
-crear la conexion
**paso 3**
-normalizar los csv  desde excel o cualquier otra,  guardarlos como csv
-crear el diagrama  de modelo entidad relacion
-crear las tablas y base de datos con sus respectivos  campos y organizar las foring key
-parsear los csv a objetos 
-plobar la base de datos 
**paso 4**
-crear los endpoins para montar el servidor y probarlos con postman
**paso 5**
-creacion de los metodos http (get,delete,post,put)
-creacion del renderizado en el front de lo requerido
